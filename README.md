# Simple Software Engineer Portfolio

A responsive portfolio built with Next.js and React.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Push this project to GitHub, import the repository in Vercel, select the Next.js framework preset, and keep the default build settings.

Before publishing, replace the placeholder name, email address, location, social links, projects, and experience in `app/page.tsx`.
